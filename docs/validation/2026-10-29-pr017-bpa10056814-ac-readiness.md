## Beijing Phase 1.5 structural runs

The three scenarios used `keep_transformer_interface`, exact voltage layers, seeded modularity planning, NetCDF export/reload, persisted mappings, and the final structural Gate. `LOW_115` protects all Bus objects above 115 kV. `LT110` protects all Bus objects at or above 110 kV. The latter was run because both fixtures contain lower-voltage layers. All figures below are **rejected candidate** counts; none is an accepted compression result.

The shared failure is `cycle_corridors`. In BASE L1, 194 corridors have parallel Lines; 91 of those are bridges in the simple corridor graph and rely on parallel multiplicity for a cycle. PyPSA quotient merges parallel Lines, leaving one Line per corridor in L2. The Phase 1.5 hard Gate correctly rejects those 91 lost protected cycle corridors, including when the Bus map is otherwise identity. Weakening this Gate or calling the candidate structurally valid would violate the accepted ring-preservation contract. The BASE L1 and L2 simple cycle rank is 25; multigraph cycle rank falls from 223 to 25, recorded as diagnostic context rather than the hard criterion.

The [structural result JSON](pr017-bpa10056814-structural-results.json) records each scenario's per-voltage source, simplified, requested, planned, actual, and final candidate Bus counts; protection endpoint counts; anchor overlaps; radial and serial opportunities; rejection reasons; final Gate details; and measured Pipeline runtime. The measured times exclude PSDCase parsing, PyPSA projection, and the extra strategy preflight. BASE's topology stage removed 129 Bus at 115 kV, four at 230 kV, and two at 10.5 kV. It rejected one additional cross-zone candidate. After BASE L1, the shared structural floor leaves only one more admissible 115 kV merge; all below-110 kV layers are saturated.

## Acceptance decision

The DC Gate, card inventory, PSDCase AC parse, supported-device projection, authoritative sidecar, and Phase 1.5 export/reload path ran. The real Beijing model **does not pass final structural acceptance** on 0.2.0 because protected parallel-only cycle corridors are aggregated. No physical fidelity, AC power flow, reactive-power, Ward, AFDPF-R, OPF, UC, or GNN conclusion is drawn. `PHYSICAL_FIDELITY_NOT_YET_EVALUATED` remains the release boundary.
